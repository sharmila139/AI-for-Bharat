## 🧪 Try These Features

1. **Soil Analysis**
   - Go to Agriculture → Soil Analysis
   - Take/upload a soil photo
   - Get AI-powered analysis

2. **Crop Recommendations**
   - Enter your location and soil type
   - Get personalized crop suggestions
   - View expected yields

3. **Language Switching**
   - Go to Settings → Language
   - Choose your preferred language
   - Entire app updates instantly
